## Why not ranamika.github.io?

`https://ranamika.github.io` can only exist for the GitHub **username** `ranamika`. That username is already taken by a different account ([github.com/ranamika](https://github.com/ranamika), created 2017, no public repos). This portfolio lives on **r-anamika**, so GitHub’s hostname is:

`https://r-anamika.github.io`

A collaborator cannot rename the GitHub user or create that other account’s Pages site.

## Anamika must do this (owner / admin only)

Kunal can push code but cannot turn on Pages or rename the repo.

Logged in as **r-anamika**:

1. Open [github.com/r-anamika/ranamikagithub.io/settings](https://github.com/r-anamika/ranamikagithub.io/settings)
2. Under **Repository name**, rename to exactly `r-anamika.github.io` → **Rename**
3. Open [Settings → Pages](https://github.com/r-anamika/ranamikagithub.io/settings/pages) (the URL will change after rename)
4. **Deploy from a branch** → `main` → `/ (root)` → **Save**

After GitHub finishes the Pages build (usually 1–2 minutes), sharing this link works:

**https://r-anamika.github.io**

Until that rename, the only possible Pages path for the current repo name would be `https://r-anamika.github.io/ranamikagithub.io/` — still 404 until Pages is enabled.
